# Memory Book Share release

- Share Flipbook: sends the existing public Heyzine URL via Web Share API; copies URL as fallback.
- Share PDF: fetches the bundled 29 MB PDF and tries file-based Web Share API where supported; falls back to sharing/copying the PDF URL.
- Save PDF: retains direct download of bundled PDF.
- All three controls are accessible in regular and immersive reader.
- Memory Book PDF and all unrelated Companion files are unchanged.
- Mobile share sheet behavior requires verification on physical iOS Safari after deployment.
