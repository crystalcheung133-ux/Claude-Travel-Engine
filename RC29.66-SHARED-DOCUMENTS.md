# RC29.67 · Engine 25.7.2 Shared Documents Candidate

- Adds shared Documents capability to VN without changing NZ RC25.7.33.
- Root Documents page is the default/shared filing location; there is no ALL folder in the UI.
- Participant folders are generated from TRIP_CONFIG.participants and appear only when populated.
- Upload defaults to Documents root; users can file under Christal, Crystal, Mero or Vivian.
- Filing is classification only, not privacy.
- Existing uploader ownership and Studio link-management rules remain separate.
- Supabase uses shared trip_documents table and trip-documents bucket, scoped by trip_id.
